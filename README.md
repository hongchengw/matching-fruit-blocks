# Farmer's Match

Match fruit cards together.

## Requirements

- **Node.js 20 or newer** (`node --version`). Needed only for the build, the local server, and
  the tests. The app itself needs nothing but a browser.
- npm, which ships with Node.

## Quick start

```bash
git clone <this-repo>
cd matching-fruit-blocks
npm install
npm run serve
```

Then open **http://127.0.0.1:4173**.
